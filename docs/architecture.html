Data Flow

AmountInputFilter validates typed/pasted input, enforces 2 decimals
3
User taps Log → SwiftData Entry inserted with do/catch
4
UndoStack pushes inverse operation for 5s undo toast
5
CaptureBookkeeping updates logCount, streak, category learning

Storage & Data Analysis
Per Entry
~200 bytes
  • • amount: Decimal (16 bytes)
  • • category: String (~20 bytes)
  • • note: String? (0-100 bytes)
  • • date: Date (8 bytes)
  • • isArchived/isPending: Bool (2 bytes)
  • • SwiftData overhead (~150 bytes)
Capacity Estimates
Years of data
  • • 10 logs/day × 365 days = 3,650 entries/year
  • • 3,650 × 200 bytes = ~730 KB/year
  • • 5 years of daily logging ≈ ~3.6 MB
  • • iOS gives apps unlimited local storage
  • • No server, no cloud sync, no subscription
  • • Data stays on-device forever (free)
Free Tier Reality
$0 forever
  • • Apple charges nothing for local SwiftData
  • • App Group container is free for all devs
  • • WidgetKit, Siri, Shortcuts — all free
  • • No API keys, no backend, no CDN
  • • Only cost: Apple Developer Program ($99/yr)
  • • User data: 100% on their device
