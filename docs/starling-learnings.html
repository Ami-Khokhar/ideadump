💡 The real insight

TapLog wins on philosophy (zero accounts, privacy, global, instant capture). Starling wins on depth (insights, AI, budgets). The gap isn't about building a bank — it's about making TapLog's on-device data as rich as Starling's bank data without the bank.

Deep Dive

Spending Intelligence — the AI play

Starling's most innovative feature (June 2025). Natural language queries on your spending data. Here's how it works and what TapLog can do.

💬

Starling's approach

Google Gemini cloud AI → query bank transaction data → return graphs + text. Requires bank connection, UK-only, opt-in privacy.

📱

TapLog's opportunity

Apple Intelligence on-device → query local SwiftData → return insights. Zero cloud, zero accounts, works offline. "How much coffee this month?" → instant answer from your phone.

🔑 Key difference

Starling's AI sees only what the bank sees (card transactions). TapLog's AI could see everything — cash expenses, planned costs, notes, categories the user created. The on-device data model is actually richer than a bank's.

💡 What this means for TapLog

Starling's revenue is almost entirely interest-based — they're a bank first, app second. TapLog is an app first. The monetisation path is different: Pro features (recap, insights, export), widgets as premium, or a one-time purchase. No interest income possible without a bank licence.

Guardrails

What we should NOT copy

🚫

Bank account requirement

Starling requires a full UK bank account. TapLog's zero-account, zero-setup philosophy is our strongest differentiator. Never add sign-up.

🌍

UK-only limitation

Starling is UK-only. TapLog is global. Don't add features that only work in one country (bank integrations, currency-specific logic).

☁️

Cloud dependency

Starling's AI runs on Google Cloud. TapLog's AI should run on-device via Apple Intelligence. Privacy is sacred — no data ever leaves the phone.

⏱️

Feature density

Starling has 30+ features. TapLog has 5-second capture simplicity. Every new feature must pass the "does this slow down logging?" test.
